# Cybersecurity basics

## 1. The four habits that stop most attacks
1. **Unique passwords** in a password manager (Echo's vault, Bitwarden, the browser's manager). Long passphrases beat clever short ones.
2. **Two-factor authentication (2FA)** on email, banking, UPI apps, social media — an authenticator app or passkey is better than SMS.
3. **Updates** on: Windows, phone, browser, router. Most attacks use old, already-fixed holes.
4. **Backups**: 3-2-1 — three copies, two kinds of storage, one offline or off-site. Test a restore once.

## 2. Spotting phishing
Urgency, a sender address that doesn't match, a link whose real address (hover/long-press) is odd, attachments you didn't expect (.zip, .html, .apk), requests for OTP/PIN. When in doubt, go to the site yourself instead of clicking. (See the scam-check skill.)

## 3. Home and office network
Change the router's admin password, use WPA2/WPA3, a separate guest Wi-Fi for visitors and smart devices, turn off WPS and remote admin, update router firmware. Public Wi-Fi: avoid banking or use mobile data.

## 4. Phones
Install apps only from the Play Store/App Store, review permissions (SMS, accessibility, screen recording are powerful), screen lock + biometric, enable Find My Device, never sideload APKs sent on WhatsApp.

## 5. Small business extras
Least privilege (people get only the access they need), remove accounts when staff leave, separate admin accounts, encrypted laptops (BitLocker), an asset list, and a one-page incident plan with phone numbers.

## 6. "I think I'm hacked"
1. From a clean device, change the email password first (it resets everything else), then bank/UPI and others; sign out of all sessions.
2. Turn on 2FA; check recovery email/phone and forwarding rules weren't changed.
3. Call the bank to freeze cards/UPI if money is at risk; report fraud on **1930** / cybercrime.gov.in (India).
4. Run Windows Security full scan; if unsure, back up files and reinstall.
5. Tell contacts not to trust messages "from you" for a while.

## 7. Ethics
Only test systems you own or have written permission to test.
