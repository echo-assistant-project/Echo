# Word documents

## 1. Styles are the secret
Use Heading 1/2/3 for headings and Normal for text instead of manual bold/size. Then: the Navigation Pane works, the table of contents builds itself, and changing a style restyles the whole document. Modify a style (right-click → Modify) for font, size and spacing.

## 2. Layout basics
- Margins, orientation and size: Layout tab. A4 for India/most of the world.
- Line spacing 1.15–1.5; space after paragraphs instead of empty lines.
- Page breaks (Ctrl+Enter) instead of pressing Enter many times.
- Section breaks when part of the document needs different orientation or page numbering.

## 3. Common tasks
- **Table of contents**: References → Table of Contents; update it before sending.
- **Page numbers**: Insert → Page Number; to start later, add a section break and untick "Link to Previous".
- **Tables**: Insert → Table; use header row repeat for long tables; avoid tabs/spaces for alignment.
- **Track Changes** for reviews (Review tab); accept/reject, then remove comments before sending.
- **Mail merge**: Mailings → Start Mail Merge → select an Excel list → insert fields (Name, Address) → preview → finish (letters, envelopes, labels).
- **Export PDF**: File → Save As → PDF for anything you send outside.

## 4. Templates worth having
Formal letter (sender, date, recipient, subject, body, signature), leave application, invoice, meeting minutes, report (title page, summary, sections, appendix), resume (see the resume skill).

## 5. Professional finish
Consistent fonts (one or two), clear headings, no orphan headings at page bottoms, spell-check, Read Aloud to catch mistakes, file name with date ("Lease-Agreement-2026-11-03.pdf").
