# Echo Command Pack

Generated by `tools/generate_command_docs.py` from `shared/commands/*.json`. Do not edit by hand.

- **3920 unique commands**: 1727 on the phone, 3809 on the PC (1616 on both).
- About **1,586,100 distinct phrasings** across both platforms (counted from the phrase grammar; slot values count once).
- Counting rule: one command is one catalog entry with its own phrases and behaviour. Phrasings and slot values (the city in “time in Tokyo”) don't add commands.
- Everything here runs deterministically from the user's words. Anything else goes to the AI, which can also ask Echo to run one of these with `run_command` (re-checked by the same parser).
- Verification: every phrase variant and example below is routed by unit tests on both platforms; behaviour on a real phone is not yet device-verified (see docs/CAPABILITIES.md).
